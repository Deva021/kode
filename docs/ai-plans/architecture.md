# Bus Dispatcher System Architecture

## 1. Database Schema (Supabase/PostgreSQL)

### Tables

#### `routes`

Stores bus route definitions.

- `id`: `bigint` (Primary Key, Identity)
- `origin`: `text`
- `destination`: `text`
- `price`: `numeric(10, 2)`
- `created_at`: `timestamptz`

#### `schedules`

Specific trips for a route.

- `id`: `bigint` (Primary Key, Identity)
- `route_id`: `bigint` (Foreign Key -> `routes.id`)
- `departure_time`: `timestamptz`
- `bus_plate_number`: `text`
- `total_seats`: `integer`
- `booked_seats`: `integer` (Default: 0)
- `created_at`: `timestamptz`

#### `tickets`

Passenger bookings.

- `id`: `bigint` (Primary Key, Identity)
- `schedule_id`: `bigint` (Foreign Key -> `schedules.id`)
- `passenger_name`: `text`
- `seat_number`: `integer`
- `status`: `text` (Enum/Check: 'booked', 'cancelled')
- `created_at`: `timestamptz`
- **Constraint**: Unique `(schedule_id, seat_number)` to prevent double booking.

## 2. SQL Initialization Script

Run this in your Supabase SQL Editor.

```sql
-- Enable UUID extension if needed in future, though we use bigint here
create extension if not exists "uuid-ossp";

-- 1. Routes Table
create table public.routes (
  id bigint generated by default as identity primary key,
  origin text not null,
  destination text not null,
  price numeric(10, 2) not null check (price >= 0),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

comment on table public.routes is 'Bus routes with origin, destination and standard price';

-- 2. Schedules Table
create table public.schedules (
  id bigint generated by default as identity primary key,
  route_id bigint references public.routes(id) on delete cascade not null,
  departure_time timestamp with time zone not null,
  bus_plate_number text not null,
  total_seats integer not null check (total_seats > 0),
  booked_seats integer default 0 not null check (booked_seats >= 0),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

comment on table public.schedules is 'Scheduled trips for specific routes';

-- 3. Tickets Table
create table public.tickets (
  id bigint generated by default as identity primary key,
  schedule_id bigint references public.schedules(id) on delete cascade not null,
  passenger_name text not null,
  seat_number integer not null check (seat_number > 0),
  status text not null check (status in ('booked', 'cancelled')),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  unique (schedule_id, seat_number)
);

comment on table public.tickets is 'Individual passenger tickets';

-- Add indexes for common queries
create index idx_schedules_route_id on public.schedules(route_id);
create index idx_schedules_departure_time on public.schedules(departure_time);
create index idx_tickets_schedule_id on public.tickets(schedule_id);
create index idx_tickets_passenger_name on public.tickets(passenger_name);
```

## 3. Next.js Folder Structure

Recommended structure for App Router (`/src`).

```

├── app
│   ├── layout.tsx              # Root layout (Navbar, Providers)

│   │   ├── [id]
│   │   │   └── page.tsx        # View/Edit specific route
│   │   └── create

│   └── tickets
│       └── page.tsx            # Search/Manage tickets

│   │   ├── button.tsx
│   │   ├── input.tsx
│   │   └── ...

│   └── layout
```
